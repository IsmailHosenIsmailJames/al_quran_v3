# Google Play Store Localized Listings (25 Languages)

This folder contains verified, ASO-optimized Google Play Store metadata for all 25 languages supported by **Al Quran**.

## 🚀 How to Add Translations in Google Play Console:
1. Go to **Google Play Console** -> **Store presence** -> **Main store listing**.
2. Click **Manage translations** -> **Add translation**.
3. Select your language, open the corresponding `listing_<lang>.txt` file.
4. Copy & paste:
   - **App title** (Max 30 chars)
   - **Short description** (Max 80 chars)
   - **Full description** (Max 4,000 chars)
